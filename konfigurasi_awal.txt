Berdasarkan tabel skema pengalamatan IP di atas, topologi jaringanmu menggunakan **Lain** sebagai router utama yang menghubungkan 3 subnet LAN berbeda ke internet (WAN).

Berikut adalah skrip otomatisasi lengkap untuk mengonfigurasi jaringan pada masing-masing node agar seluruh host terhubung satu sama lain dan bisa mengakses internet.

### 1. Konfigurasi Router Utama (Node Lain)

Jalankan skrip ini di terminal node **Lain**:

```bash
#!/bin/bash
# Konfigurasi IP pada masing-masing interface router Lain
dhclient eth0 2>/dev/null || true

ip addr flush dev eth1
ip addr add 192.224.1.1/24 dev eth1
ip link set eth1 up

ip addr flush dev eth2
ip addr add 192.224.2.1/24 dev eth2
ip link set eth2 up

ip addr flush dev eth3
ip addr add 192.224.3.1/24 dev eth3
ip link set eth3 up

# Aktifkan IP Forwarding & NAT (MASQUERADE ke arah WAN eth0)
sysctl -w net.ipv4.ip_forward=1
iptables -t nat -F
iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE

echo "[+] Router Lain berhasil dikonfigurasi!"

```

### 2. Konfigurasi Node Klien & Server

Jalankan perintah berikut sesuai dengan nodenya masing-masing:

1. **Node Alice:** LAN 1 - Host 1.
```bash
ip addr flush dev eth0
ip addr add 192.224.1.2/24 dev eth0
ip link set eth0 up
ip route add default via 192.224.1.1
echo "nameserver 8.8.8.8" > /etc/resolv.conf

```
